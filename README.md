# AI Business Suite

An all-in-one, AI-integrated business platform that runs **entirely in your browser** — no installs, no server, no cost.

## How to run
1. Double-click `index.html` (opens in your default browser)
2. All your data is saved automatically in the browser (localStorage)
3. Use **Export Data** in the top bar for backups

## Modules
| Module | What it does |
|---|---|
| Dashboard | Revenue, products, customers, stock, sales overview |
| Store | Add/edit products, customer cart, checkout → orders |
| Orders | Track order status (Pending → Paid → Delivered → Cancelled) |
| Booking | Services + appointments (book, complete, cancel) |
| CRM | Customers (spent tracking) + leads pipeline (New → Contacted → Won) |
| Inventory / POS | Stock levels, low-stock alerts, point-of-sale register, sales history |
| Landing Page | Customer-facing preview with the AI chatbot widget |
| AI Tools | AI content generator (descriptions, posts, emails, ads) + AI assistant chat |
| Settings | Business info, currency, AI API key, data backup/reset |

## Free AI (Google Gemini)
1. Go to **https://aistudio.google.com/apikey**
2. Sign in with any Google account → **Create API key** (free tier, no charge)
3. Copy the key → open the app → **Settings** → paste key → **Save** → **Test AI Connection**

The AI assistant answers questions about your products, services, stock, and business automatically from your data.

## Notes
- The API key is stored **only in your browser** (never sent anywhere except Google's API).
- All business data lives in your browser's localStorage. Use **Export Data** to back up.
- Reset everything anytime from **Settings → Reset All Data**.
